# نواقص الصيدلية — غلاف Android

هذا المشروع ينشئ تطبيق Android خفيفًا يفتح النظام المنشور عبر HTTPS داخل WebView، مع دعم الجلسات المحلية، الرجوع داخل التطبيق، وحالة خطأ عربية قابلة لإعادة المحاولة عند انقطاع الشبكة.

## بيانات الحزمة

| البند | القيمة |
|---|---|
| اسم التطبيق | نواقص الصيدلية |
| معرّف الحزمة | `com.ckf404.pharmacyshortages` |
| الحد الأدنى لإصدار Android | Android 7.0 (API 24) |
| الرابط الذي يفتحه التطبيق | `https://pharmashrt-lxbcyjhj.manus.space/` |

## تثبيت النسخة التجريبية

الملف الناتج هو **APK تجريبي موقّع بشهادة Android Debug**. انقله إلى هاتف Android، ثم افتحه واسمح بالتثبيت من المصدر الذي استخدمته عند طلب النظام. لا يحتاج التطبيق إلى أي صلاحية غير الإنترنت.

للنشر في متجر Google Play يلزم إنشاء مفتاح توقيع إصدار خاص بالمالك وبناء `release` موقّع به.
